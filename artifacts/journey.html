Artifact 02 · Journey

User Journey & Flow

Mapping an Unrot user's path from first open to a reason to return tomorrow.

Entry

User installs or opens Unrot, completes onboarding, and finishes an initial lesson. Value is communicated, but the next visit is undefined.

Current friction

  • Home presents multiple independent activities with no "do this now."
  • Progress is easy to lose between sessions.
  • No daily close — session ends without a hook for tomorrow.

Proposed journey

Open app ↓ See today's challenge (not a menu) ↓ Complete one learning activity ↓ Earn points + streak tick ↓ Calendar shows today filled ↓ Prompt: come back tomorrow

Successful outcome

The user leaves with a completed daily task, visible progress, and a reason the next open is valuable — not a blank catalog.
