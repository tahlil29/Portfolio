Artifact 04 · Metrics

Product Metrics Tree

Connecting Unrot's business goal (users who keep learning) to leading indicators and user behavior.

North star

Weekly learners who complete at least one learning activity.

Tree

Business: retained learners ↓ Product: D1 / D7 retention ↓ Leading: daily challenge participation ↓ Behavior: lesson completion, sessions / user, activities / user ↓ Habit: streak continuation rate

How I would use it

If D1 is weak but challenge start is high, the activity itself is the leak. If challenge start is weak, the home-screen prompt is the leak. I would not treat leaderboard views as a success metric until the core loop is healthy.
