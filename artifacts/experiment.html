Artifact 06 · Experiment

Experiment Design

A proposed test for Unroad Daily Challenge. Not a live A/B — structure I would use before shipping.

Hypothesis

If new users see a single Daily Challenge on home after first session, then D1 return rate will increase because the next visit has a clear job to do.

Structure

  • Audience: users who complete first-session onboarding.
  • Control: current home (activity collection).
  • Treatment: Daily Challenge module pinned first + streak on completion.
  • Duration: enough new users to read D1 and a first look at D7 (not a one-day peek).

Success metrics

  • Primary: D1 retention
  • Secondary: challenge participation, lesson completion, sessions / user
  • Guardrail: time-to-first-lesson should not get worse (challenge must not block content)

Decision criteria

  • Ship if D1 lifts without hurting first-lesson completion.
  • Iterate copy/placement if challenge start is low.
  • Kill or redesign if users start challenges but completion collapses vs control.
