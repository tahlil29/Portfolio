Product Requirement Document

Sample PRD for Unroad Daily Challenge — problem, goals, user stories, requirements, edge cases and success metrics.

Problem

After a first Unroad session, users have limited reason to return. Content exists, but the product does not create a daily habit loop (clear task, progress, and a reason to come back tomorrow).

Goals

  • Give every returning user one obvious task on the home screen.
  • Make progress visible without adding cognitive load.
  • Instrument D1 / D7 retention and challenge participation before claiming impact.

Non-goals

  • Full social network or competitive ranking as a P0.
  • Paid rewards or a new currency economy in v1.
  • Rebuilding the lesson catalog.

User stories

  • As a first-day learner, I want a single challenge so I know what to do next without browsing.
  • As a returning learner, I want to see my streak so yesterday's effort still matters.
  • As a product team, I want challenge_start and challenge_complete events so we can see drop-off.

Requirements

  1. Home surfaces today's Daily Challenge above other activities.
  2. Challenge maps to an existing learning activity (no new content type in v1).
  3. Completion awards points and updates streak + calendar.
  4. Missed days reset streak; calendar still shows history.
  5. Leaderboard is optional and hidden until P2.

Edge cases

  • User completes challenge then reopens the app the same day — show completed state, not a new challenge.
  • Timezone change overnight — challenge keyed to local date.
  • Offline completion — queue event; don't double-count points.
  • Empty catalog — hide challenge module rather than showing an error card.

Success metrics

  • D1 retention, D7 retention
  • Daily challenge participation rate
  • Lesson completion rate among challenge starters
  • Streak continuation rate (day n → n+1)
