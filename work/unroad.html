Case Study 01 · Unroad

Improving Day-1 Retention for Unroad

Designed a retention-focused product experience based on observed gaps in user motivation and repeat engagement.

Product StrategyUXRetentionGrowthPrototyping

01 — Context

Unroad provides a learning experience designed to help users build knowledge through structured lessons and activities.

02 — Problem

While the onboarding experience communicates the product's value, users may have limited motivation to return after completing their initial session.

03 — Observation

The product provides learning content, but the experience can be strengthened by creating a clearer sense of progress, challenge and daily motivation.

04 — Product Opportunity

How might we create a stronger reason for users to return to Unroad every day?

05 — Proposed Solution

Daily Learning Loop

Open App ↓ Daily Challenge ↓ Complete Learning Activity ↓ Earn Points ↓ Progress / Streak ↓ Leaderboard ↓ Come Back Tomorrow

06 — Features

  • Daily Challenges — Give users a clear task to complete each day.
  • Rewards — Introduce points/rewards for completing learning activities.
  • Progress — Show users how far they've progressed.
  • Leaderboard — Create optional social motivation.
  • Daily Calendar — Give users a visual reason to maintain their learning streak.
  • Connected Activities — Make the home screen feel like a journey rather than a collection of independent features.

Impact × Effort, used to sequence what should ship first.

08 — Success metrics I would track

This was a product proposal rather than a live experiment, so these are the metrics I would instrument — not claimed results.

  • D1 retention
  • D7 retention
  • Lesson completion rate
  • Daily challenge participation
  • Sessions per user
  • Average learning activities / user
  • Streak continuation rate
