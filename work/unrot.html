Case Study 02 · Unrot

Unrot Daily Challenge

Turning 5-minute learning into a daily habit

Product StrategyRetentionUXExperimentationPrototyping

A product intervention designed to improve Day-1 retention by turning an episodic learning experience into a lightweight daily habit — without redesigning the entire product.

View prototype View deck (PDF)
Problem

The problem

Learning happened. Returning didn't.

Unrot helps users learn AI, but the experience could feel episodic rather than habitual. Three gaps stood out:

  • No clear next action after completing a lesson
  • Progress wasn't sufficiently visible
  • No compelling reason to return the following day
The problem wasn't the value of learning. It was the lack of a reason to return.

Users could discover lessons and learn, but after completing a lesson there was no strong next action, visible progress or compelling reason to come back tomorrow.

Insight

Product opportunity

How might we turn learning into a daily habit?

Introduce a lightweight daily challenge that gives users a clear next action, visible progress and a reason to return.

This was a focused intervention on the existing experience — not a full product redesign.

Hypothesis

Hypothesis

If we give users an immediate product experience and introduce a lightweight daily challenge with visible progress and rewards, users will have stronger motivation to return the following day, improving D1 retention.

Framed as a hypothesis to validate — not a guaranteed result. No fabricated retention lift.

Behavioral loop

The intervention transforms a single learning session into a repeatable loop: users learn, complete a challenge, earn a reward, see progress and receive a clear reason to return.

Discover ↓ Learn ↓ Complete ↓ Earn ↓ Track progress ↓ Return ↺

Deliver value before asking for commitment

Rather than redesigning onboarding, I identified a smaller intervention with potentially higher leverage: let users experience the product's value before asking them to form a daily habit.

Existing onboarding ↓ Interests + goals ↓ First lesson preview ↓ User experiences real value ↓ Home ↓ Daily challenge

Decision

Reduce decision fatigue

Product decision

Prioritize the Daily Challenge over a grid of equal activities.

Why Users need one obvious next action rather than more choices.

Action → Progress → Exploration

  1. What should I do? Today's learning.
  2. Why should I keep doing it? Progress, streak and XP.
  3. What else can I explore? AI News, Workshops, Interview Prep.

Gamification is a layer — not the product

Core loop: Learning → XP → Progress → Streak → Return

Leaderboard: optional motivation layer — users should still experience the full habit loop even if they ignore it.

I treated gamification as a supporting mechanism rather than the core product experience. XP and streaks reinforce learning behavior, while the leaderboard remains optional.

Metric

How would we know it worked?

Proposed success signals — not measured results. Any lift would need to be validated in a live experiment.

Primary metric (proposed): D1 retention — users who return the following day.

Secondary signals (proposed):

  • Challenge completion rate
  • Lesson completion during first session
  • First-session lesson start rate
  • Reward screen → next-day return
  • Streak continuation
